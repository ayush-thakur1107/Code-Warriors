# Data documentation

**Everything in `data/` is synthetic.** None of it is real AIS data or an observed spill.

## `data/raw/*.csv` — synthetic spill-area datasets
Generated by `python ml/generate_data.py` (fixed seeds, reproducible).

| Column | Unit | Meaning |
|---|---|---|
| `scenario_id` | – | One simulated incident (e.g. `train-0042`); rows of a scenario share inputs except time |
| `initial_area_km2` | km² | Area at t = 0 |
| `wind_speed_ms` | m/s | Wind speed (direction not modelled) |
| `current_speed_ms` | m/s | Current speed (direction not modelled) |
| `elapsed_hours` | h | Time since spill start |
| `area_km2` | km² | **Target**: synthetic footprint area at `elapsed_hours` |

| File | Scenarios × rows each | Seed | Input ranges |
|---|---|---|---|
| `synthetic_train.csv` | 300 × 10 | 11 | area 0.5–20 (log-uniform), wind 0–20, current 0–1.5, time 0–72 |
| `synthetic_val.csv` | 80 × 10 | 22 | same |
| `synthetic_test.csv` | 80 × 10 | 33 | same |
| `synthetic_stress_extrapolation.csv` | 60 × 10 | 44 | **deliberately outside**: area 20–40, wind 20–30, current 1.5–2.5, time 72–120 |

### Data-generating process
```
expected = A0 × (1 + 0.35·√t·(1 + 0.06·wind + 0.5·current)) × exp(−0.002·t·max(0, wind − 8))
area     = expected × scenario_factor × row_noise
```
`scenario_factor` ~ log-normal(σ=0.10) is hidden per scenario; `row_noise` ~ log-normal(σ=0.03).
The first row of each scenario is at t = 0.

**Assumptions:** area grows like √t, faster with wind/current; strong wind (> 8 m/s) disperses oil over time.
These are invented for demonstration, loosely inspired by the idea that slicks spread and weather, and
**not validated oil-spill physics**.

### Leakage control
Each split has its own seed and scenario ids. Tests check ids are disjoint across splits and that no input combination repeats between train and test.

## `data/samples/` — demo JSON
- `vessel_routes.json`: 6 invented vessels (`SYN-001`…`SYN-006`), hourly position reports (UTC), designed to exercise the ranking cases (close/simultaneous, close but early, AIS gap, far, no data). Regenerate: `python ml/generate_sample_json.py`.
- `spill_scenario.json`: default demo incident (location, start time, initial area, wind, current, drift heading used by the drawing only).

Coordinates are WGS-84 decimal degrees; times ISO 8601 UTC.
